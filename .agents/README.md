# Project Context

This folder contains project documentation for AI coding assistants. Start here to understand the project.

## Files

| File | Purpose |
|---|---|
| `project.md` | What is this project, who is it for, what are the goals |
| `architecture.md` | Technical architecture, folder structure, conventions |
| `roadmap.md` | Feature progress — what's done, what's in progress, what's next |
| `decisions.md` | Every architectural and technical decision, with reasoning |
| `features/` | One file per feature with details (APIs, workflow, edge cases) |

## Reading Order

1. `project.md` — understand the product
2. `architecture.md` — understand the codebase
3. `decisions.md` — understand why things are the way they are
4. `features/{relevant-feature}.md` — understand a specific feature in detail
5. `roadmap.md` — see what's left to do
